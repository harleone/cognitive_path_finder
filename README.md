# cognitive path finder
## Project Versions

This repository contains two implementations:

### 1. Simple Baseline
`path_finder_simple.py`
A minimal neuron visualization used as the foundation.

### 2. Cognitive Path Finder
`path_finder_advanced.py`
An interactive neuro-inspired system with connections,
signal propagation, and cognitive path exploration.

The advanced version was built incrementally from the
simple baseline.
